# YuanNIC - FPGA SmartNIC for AI and Acceleration
**YuanNIC** is the FPGA SmartNIC developed by YuanGrid.
It features hardware link timing optimization for high-speed interconnect and protocol offloading, with a natively integrated RDMA acceleration engine.
It supports wire-rate packet processing, ultra-low transmission latency, 400G/800G high-speed optical ports, programmable protocol offload, high-precision time synchronization and elastic virtualization scaling.
It targets AI clusters, high-speed interconnection, low-latency storage and intelligent offloading workloads.
